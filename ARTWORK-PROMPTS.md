# Cave Oops! artwork

The project artwork was generated with ChatGPT's built-in image-generation tool. The three reference screenshots supplied by the user guided only the readable side-view scale, chunky outlines, and playful underground mood. All characters, tiles, props, and layouts are original.

## Actor atlas

Create a transparent pixel-art atlas for an original hard comedic platformer: a clumsy courier hero with a teal scarf and oversized backpack in idle, running, jumping, falling, stunned, flattened, and victory poses; a grumpy bat, stone beetle, one-eyed mushroom, skeleton guard, and angry scarab. Use crisp consistent pixel clusters, dark brown outlines, expressive faces, a strict grid, generous gutters, complete silhouettes, transparent alpha, and no text or watermark.

Saved as `public/assets/cave-oops-actors-chatgpt.png`.

## Environment atlas

Create two modular transparent pixel-art stage kits: a warm sandstone temple set and a dark blue cave/red clay mine set. Include repeatable blocks, ledges, corners, columns, arches, ladders, bridges, ropes, spikes, gems, gold, pots, skulls, buttons, doors, and spring platforms. Keep every piece separated in a strict grid with transparent alpha and no text or watermark.

Saved as `public/assets/cave-oops-tiles-chatgpt.png`.

## Trap and effects atlas

Create transparent pixel-art sprites for arrow traps, retracting spikes, swinging weights, boulders, impact effects, checkpoints, a cage, key, gems, health food, crates, explosive barrels, moving and ghost platforms, bounce pads, and an animated exit portal. Keep consistent scale, aligned animation frames, clean gutters, transparent alpha, and no text or watermark.

Saved as `public/assets/cave-oops-traps-chatgpt.png`.
